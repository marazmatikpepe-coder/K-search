# K-search
- `docs/` — K-search для GitHub Pages (Settings → Pages → main → /docs)
- Запуск: `npm install && npm start`
- .exe: Actions → Build exe → Artifacts → K-search-exe (K-search-Setup.exe — установщик с выбором папки и регистрацией браузера, K-search-portable.exe — без установки)
- F12 — консоль интерфейса, Ctrl+F12 — консоль вкладки
