# K-search
- `docs/` — K-search для GitHub Pages (Settings → Pages → main → /docs)
- Запуск из исходников: `npm install && npm start`
- .exe: Actions → Build exe → Artifacts → K-search-exe (Setup — установщик с выбором папки и регистрацией браузера, portable — без установки)
- F12 — консоль интерфейса, Ctrl+F12 — консоль вкладки
